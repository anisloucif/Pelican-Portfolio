OpenAI lance AgentKit pour créer et déployer des agents IA

OpenAIAgentKitagents IAoutils de développement

Résumé

Le 6 octobre 2025, lors de sa conférence DevDay, OpenAI a présenté AgentKit, un ensemble d'outils destiné aux développeurs et aux entreprises pour construire, déployer et améliorer des agents IA. AgentKit comprend notamment :

  • Agent Builder : un éditeur visuel pour concevoir le déroulement d'un agent par glisser-déposer, avec gestion des versions ;
  • ChatKit : des composants pour intégrer une interface de discussion avec un agent dans son propre site ou application ;
  • des outils d'évaluation pour mesurer la qualité des réponses d'un agent ;
  • un registre de connecteurs pour administrer les accès des agents aux données et aux outils de l'entreprise.

Ce que ça change pour un développeur

  • La création d'agents se rapproche du low-code : le développeur se concentre sur l'intégration (API, données, sécurité) plutôt que sur la mécanique de l'agent.
  • L'évaluation devient une étape à part entière, comme les tests en développement classique. Ça rejoint ce que j'ai fait en QA pendant mon stage.

Mon avis

Le risque est la dépendance à un fournisseur. Les standards ouverts (MCP, A2A) servent justement à limiter ce risque.
