Le protocole Agent2Agent (A2A) de Google rejoint la Linux Foundation

A2AGoogleLinux Foundationagents IAinteropérabilité

Résumé

Présenté par Google en avril 2025, Agent2Agent (A2A) est un protocole ouvert qui permet à des agents IA de communiquer entre eux, même s'ils ont été créés par des éditeurs différents : un agent peut découvrir ce qu'un autre sait faire, lui confier une tâche et suivre son avancement. En juin 2025, Google a transféré le projet à la Linux Foundation, pour qu'il soit géré de façon neutre avec d'autres grands acteurs du secteur.

Ce que ça change pour un développeur

  • MCP relie un agent à des outils ; A2A relie des agents entre eux. Les deux sont complémentaires.
  • Une gouvernance neutre rassure les entreprises : le standard ne dépend plus d'un seul éditeur.
  • Pour une plateforme d'orchestration comme celle observée en stage, A2A permet de faire coopérer des agents spécialisés (un agent « comptabilité », un agent « support »…).

Mon avis

C'est l'équivalent de ce qu'a été HTTP pour le web : sans protocole commun, chaque agent resterait enfermé dans son écosystème.
